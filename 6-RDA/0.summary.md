## file overview

1. Code that generated the redundancy analysis (RDA) and figures using the cluster (**1.colias-RDA.R**)
    * Inputted file containing bioclim data (**colias_bioclim-elev.csv**)
    * Outputted file showing all significant SNPs (**1.SNPs-env.only...**)
2. Code for the allele frequency analysis (**2.colias-allele-freq.R**)
    * Inputted files (**env_by_site.csv**, **colias_bioclim-elev.csv**)
    * Use **2.allele-freq-cluster-workflow.txt** alongside the VCF file to create **colias_freq_by_pop.csv**
3. Code for the gene enrichment analysis
    * Code for running the analysis using Gowinda v1.12 (**3.gowinda.R**)
    * Required files for the analysis (**gene_names_key.txt** and **gowinda_results.txt**)
